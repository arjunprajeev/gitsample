undo in git
1. modified file but not staged : git restore <filemname>
                                  git restore .  (all files)
                                  PS D:\gitsample> git restore db.py
                      
2. modifed and staged : git restore --staged <filemname>
                                  git restore --staged .  (all files)       

3.  PS D:\gitsample> git restore --staged db.py
    PS D:\gitsample> git restore db.py

undo commit : git reset --soft HEAD~1     (removes only commit staged stmts will be remained)

undo commit and delete staged : git reset HEAD~1

undo commit and delete all changes : git reset --hard HEAD~1


Deleting old commits : git rebase -i HEAD~<number>
